Install Meta-System 3.7

An evaluation install for your own computer: one download, one command, then a conversation.

Where the installer stands

This is an early build, for evaluation. It has installed, uninstalled, reinstalled and restarted cleanly on a Debian 12 test machine. It has not yet run on Windows (WSL2), and it hasn't run on Ubuntu 26.04, though the pieces that differ there were tested separately. Your install may be the first on your setup, so anything that confuses you is worth a note, not just errors.

What you need

  • Windows 10 or 11 with WSL2 (Ubuntu running inside Windows), or an Ubuntu or Debian Linux computer or virtual machine. Use Ubuntu 24.04 or newer.
  • Admin rights on the computer.
  • Your own Claude subscription. Meta-System's chat runs on your Claude login.
  • About 15 minutes.

On Windows: set up Ubuntu first

Skip this if you're already on Linux.

  1. Open PowerShell as administrator (right-click the Start button, choose "Terminal (Admin)") and run: 
    wsl --install -d Ubuntu
    Restart Windows if it asks you to.
  2. Open Ubuntu from the Start menu. The first time, it asks you to choose a username and password. The installer asks for this password later.
  3. Download the installer above. It lands in your Windows Downloads folder.

Everything from here on is typed into the Ubuntu window.

Install

Copy the installer into Ubuntu and run it. Replace YOUR-WINDOWS-NAME with the name of your Windows user folder:

cp /mnt/c/Users/YOUR-WINDOWS-NAME/Downloads/ms37-installer-*.tar.gz ~/
cd ~ && tar xzf ms37-installer-*.tar.gz && cd ms37-installer-*/
./install.sh

On Linux, skip the cp line and run the rest from wherever the download landed.

The installer runs seven steps and checks each one as it goes:

  1. It asks for your password (the Ubuntu one, on Windows).
  2. Partway through, it opens Claude Code for you to log in with your own Claude account. If no browser opens, copy the link it shows into your browser, log in, and paste the code back. Then type /exit and the installer carries on.
  3. At the end it prints an address starting http://127.0.0.1:8791/. Open it in your browser. On Windows, that's your normal Windows browser.

If a step stops with an error, nothing is broken. Take a screenshot, fix what it says if you can, and run ./install.sh again. It picks up where it stopped.

The first time it opens

A Setup chat starts by itself and says hello. That's the onboarding interview: it asks about you and your work, then builds your starting system from your answers. It only starts by itself once. Take your time with it.

The code at the end of the address is the password to your Meta-System. Keep the address private. It stays the same, so a bookmark keeps working.

After a restart

On Linux, Meta-System starts by itself when the computer starts. On Windows, open Ubuntu first and keep its window open while you use Meta-System. If the address doesn't load, run this in Ubuntu:

~/ms37-installer-*/start-metasystem.sh

It starts Meta-System again and prints the same address.

What to try, and what to note

  • The setup interview. Did it make sense? Where did it lose you?
  • Every pane. Which show content, which are empty, and which show an error. Some panes were built for tools that aren't part of this install, and finding out which is part of the point.
  • A terminal pane. Does it open, and can you type in it?
  • Decision Log and Idea Bank. Add a test entry to each. Does it appear?
  • Anything mentioning a person, path or project that isn't yours. The code still carries notes from its own development, so some of these are expected. They're still worth a note.

Send screenshots and notes to the person who gave you this link.

Removing it

~/ms37-installer-*/uninstall.sh

This deletes the metasys account the installer created, and everything Meta-System stored in it. It asks you to type remove first. On Windows you can also remove Ubuntu entirely from Settings, Apps.

What the installer does

It installs a few standard packages (git, tmux, Python's websockets, curl, cron), creates a separate account named metasys so everything stays apart from your own files, puts the code and three starting files in that account, installs Claude Code there, creates the database, starts the server, and sets it to start after a restart. The server only accepts connections from the same computer. The user guide explains what each part is.
