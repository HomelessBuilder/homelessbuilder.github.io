Meta-System 3.7

Everything for a test install: the installer itself, how the onboarding interview works and where it stands, and how the system works once it is running.

Meta-System is a working environment built around Claude Code: several AI sessions with defined roles, a shared record of decisions and ideas, and a browser app that puts all of it on one screen. Version 3.7 is the line meant to work for someone other than the person who built it.

All three pages say what is ready and what isn't. Some pieces are finished and in daily use. Others are built but not yet proven on a real install. The pages mark which is which.

  1. Page oneInstallDownload the installer, install on Windows (WSL2) or Linux, and what to note while you try it.
  2. Page twoThe onboarding interviewThe first-run conversation that is meant to set up a new install, what it builds, and where it stands today. It is built into 3.7 as the Setup persona, tested on a practice install, and not yet run on a real one.
  3. Page threeUser guideHow the system works: panes, sessions, personas, workspaces, restarting after a reboot, the decision log and idea bank, and the rules every session follows. Includes what an install consists of today.
